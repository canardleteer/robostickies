Keep the papercut tag, add resolved after verifying the fix in its affected environment, record evidence, then archive. For MCP fixes, install the binary and verify through a newly started agent MCP connection. Use either a user-confirmed restart of the testing session or a separate fresh agent process with its own MCP server; the current session may continue. Archived status alone does not prove resolution. Preserve the note's visibility when selecting or creating an outcome definition.
