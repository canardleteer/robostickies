the guide for the task:

| Guide | Topics |
| --- | --- |

| [Markdown storage](storage.md) | Edit source files and share them in Git |
| [Private notes and configuration](privacy-and-configuration.md) | Keep notes local or publish reviewed copies |
| [Search and review](search-and-review.md) | Select matching notes and prepare a complete review |
| [Shared editing](shared-editing.md) | Reconcile conflicts between cooperating writers |
| [Resolution and adoption](outcomes.md) | Record verification and adoption outcomes |
| [MCP and agent orientation](mcp.md) | Connect an agent to the stdio server |
| [Diagnostics and cache recovery](maintenance.md) | Validate sources and recover the index |

For work on robostickies itself, see the [development guide](../../README.md#development).
